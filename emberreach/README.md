# 余烬之境 · Emberreach

一个可以在浏览器里直接游玩的中世纪剑与魔法开放世界原型。整个游戏只有一个 HTML 文件，依赖 Three.js r128（通过 cdnjs 加载），不需要构建。

## 运行

直接用浏览器打开 `index.html`，或者在本目录启动任意静态服务器：

```bash
python3 -m http.server 8000   # 然后访问 http://localhost:8000
```

需要键盘和鼠标。

## 世界

- **灰石镇**：有城墙的城镇，城里有大教堂钟楼、集市、守卫和居民
- **镜湖**：东边的湖，湖心岛上有宝箱，湖岸有一座灯塔
- **盗匪营地**：西南森林里，有木栅栏、帐篷、瞭望塔和首领
- **古代废墟**：东南山丘上的残垣和高塔
- **霜脊山**：地图边缘的雪山

## 系统

| 系统 | 说明 |
|---|---|
| 自由攀爬 | 贴着任何建筑按住 W 就能爬上去；矮墙会自动翻越；Space 蹬墙跳 |
| 瞭望烽火 | 爬上四座高塔并点亮烽火，可以揭开地图并设为重生点 |
| 信仰之跃 | 从高处跳进干草堆不会受伤（下落时会自动修正落点） |
| 潜行 | 蹲伏可以缩小被发现的范围；在草丛或草堆里蹲着会完全隐身；夜晚守卫的视野更短 |
| 刺杀 | 从背后接近、在敌人未察觉时，或者从空中落下时按 F |
| 火焰 | 火球可以点燃树木、草丛、干草、木屋和帐篷，火势会蔓延，也会点燃人 |
| 冰霜 | 冻结范围内的敌人并扑灭火焰；在水边施放会冻出一块可以行走的浮冰 |
| 闪现 | 朝视线方向瞬移，可以闪到屋顶 |
| 犯罪与通缉 | 攻击平民或守卫，如果被人目击就会被通缉；无人目击则不会；甩掉追兵一段时间后通缉会解除 |
| 昼夜 | 一天 8 分钟（按住 T 可以加速），夜晚更适合潜行 |

没有主线。按 J 可以看到一些可选的"传闻"目标。

## 代码结构

`index.html` 中的脚本按以下顺序组织：噪声与地形 → 场景与材质 → 碰撞体 → 城镇、营地、废墟生成 → 树木与草丛（InstancedMesh）→ 粒子 → 音效（WebAudio 合成）→ 角色 → 物理与视线 → 火焰系统 → 战斗 → 法术 → 玩家 → NPC AI → 天空与镜头 → 地图与 HUD → 输入 → 主循环。

调试用的钩子挂在 `window.__emberreach` 上，其中 `sim(秒数, {KeyW:true})` 可以在不渲染的情况下推进模拟，方便做自动化测试。
